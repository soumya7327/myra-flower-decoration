# MYRA Flower Decoration

A responsive event-decoration website built with **React, Vite, Tailwind CSS 4, Framer Motion, and Lucide React**, featuring a luxury black-and-gold design.

**Live Demo:** https://myra-flower-decoration.vercel.app/

## Tech Stack

- **Frontend:** React
- **Build Tool:** Vite
- **Styling:** Tailwind CSS 4
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Deployment:** Vercel

## Features

- Responsive layout for desktop and mobile.
- Luxury black-and-gold visual theme.
- Event category galleries with separate portfolio and inspiration sections.
- Catalogue viewing and download.
- Validated inquiry form with WhatsApp click-to-chat handoff.
- Direct gallery routes for different event categories.
- Optimized local images and reusable image data configuration.

## Run Locally

**Requirements:** Node.js and npm.

1. Clone this repository:

   ```bash
   git clone https://github.com/soumya7327/myra-flower-decoration.git
   cd myra-flower-decoration
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open the local URL printed by Vite.

## Production Build

Build the project:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Project Structure

- `src/` — React application, components, styles, and data.
- `public/images/` — Website images and visual assets.
- `public/catalogue/` — Downloadable catalogue PDF.
- `vercel.json` — Production routing configuration.

## Deployment

The website is deployed on Vercel and connected to the GitHub repository. Pushing changes to the `main` branch can trigger a new production deployment.
